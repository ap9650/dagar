# A note for parents, to send before the class uses Dagar

Copy one of these into WhatsApp or a class group. Send it **before** the link
goes out, not after.

## Why this exists

Dagar does not yet have the in-app parental consent flow that a direct-to-public
children's app needs — a parent's email, an itemised permission mail, an account
that stays inactive until an adult approves it. That is built after the
buildathon, before Dagar goes anywhere beyond a teacher handing it to her own
class (see `DECISIONS.md`).

For a classroom deployment the consent channel is the one schools have always
used: the teacher tells the parents what the material is and what it collects.
**This note is that.** It is short on purpose — a message nobody reads protects
nobody.

If a parent says no, that child does not get the link. That is the whole
mechanism, and it only works if the note goes out first.

## What to do if a parent asks a question you cannot answer

Send them to `dagar-ap19.vercel.app/privacy`, which lists everything in plain
words in both languages, or to `/for-parents`, which explains the weekly summary.

A parent can ask for their child's information to be deleted at any time, and it
will be — that promise is on the privacy page and it has to be honoured.

**There is no support address in the app yet**, so the privacy page routes
deletion requests through you: "tell the teacher or the adult who shared Dagar
with you". That is true for a classroom and it is a stopgap. Before Dagar goes
to anyone you have not met, it needs either a real contact address on the
privacy page or — better — a **delete my account** control in Settings. Pick one
before wide release; the promise is already made.
